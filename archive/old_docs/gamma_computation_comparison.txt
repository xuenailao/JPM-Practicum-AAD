  GAMMA计算方法对比：Edge-Pushing修复前 vs 修复后

┌─────────────────────────────────────────────────────────────────────────────┐
│ 方法1: Edge-Pushing 修复前 (WRONG - Gamma = 0)                              │
└─────────────────────────────────────────────────────────────────────────────┘

  PDE求解: 得到价格网格

    S_grid:  [0,   50,  100,  150,  200,  250]
    V_grid:  [0,  4.2, 10.5, 18.3, 27.1, 36.5]
                     ↑
                   这些值包含了S依赖性

  线性插值获取V(S0=105):

    找到: 100 < 105 < 150
    权重: w = (105-100)/(150-100) = 0.1

    V(105) = (1-0.1)×10.5 + 0.1×18.3
           = 9.45 + 1.83
           = 11.28

  ❌ 问题：V(S0) = (1-w)·V[i] + w·V[i+1] 是S0的线性函数！

    ∂V/∂S0 = (V[i+1] - V[i])/(S[i+1] - S[i])
           = (18.3 - 10.5)/(150 - 100)
           = 0.156  (常数！)

    ∂²V/∂S0² = ∂/∂S0(0.156) = 0  ❌❌❌

  计算图分析:

    σ ──┐
        ├──> [PDE] ──> V[0], V[1], V[2], ... ──┐
    S0 ─X  (S0不在图中)                        │
                                               ├──> 线性插值 ──> price
                                               │    (权重=常数)
                                               ┘

    AAD无法追踪S0 → Gamma = 0


┌─────────────────────────────────────────────────────────────────────────────┐
│ 方法2: Edge-Pushing 修复后 (CORRECT - Gamma ≠ 0)                            │
└─────────────────────────────────────────────────────────────────────────────┘

  PDE求解: 同样得到价格网格

    S_grid:  [0,   50,  100,  150,  200,  250]
    V_grid:  [0,  4.2, 10.5, 18.3, 27.1, 36.5]

  找到S0=105最近的网格点:

    idx = 2 (对应S=100)

  ✅ 关键：不用插值，直接在网格上计算导数！

  Gamma = [V[idx+1] - 2×V[idx] + V[idx-1]] / dS²
        = [18.3 - 2×10.5 + 4.2] / (50²)
        = [18.3 - 21.0 + 4.2] / 2500
        = 1.5 / 2500
        = 0.0006  ✅✅✅

  为什么有效？

    V[i]本身就是V(S_i)的值，不同的i对应不同的S
    → V[i+1] - V[i] 反映 ∂V/∂S
    → (V[i+1] - V[i]) - (V[i] - V[i-1]) 反映 ∂²V/∂S²

  直观理解（以Delta为例）:

    Delta_right = (V[idx+1] - V[idx]) / dS
                = (18.3 - 10.5) / 50
                = 0.156

    Delta_left = (V[idx] - V[idx-1]) / dS
               = (10.5 - 4.2) / 50
               = 0.126

    Gamma = (Delta_right - Delta_left) / dS
          = (0.156 - 0.126) / 50
          = 0.0006  ✅

  混合方法:

    σ ──> [PDE] ──> V[0], V[1], ... ──┬──> AAD ──> Vega  ✅
                                      │
    S0 ──────────────────────────────┴──> 网格FD ──> Gamma ✅
         (不在图中，但直接用数值FD)


┌─────────────────────────────────────────────────────────────────────────────┐
│ 方法3: Bumping (CORRECT - Gamma ≠ 0)                                        │
└─────────────────────────────────────────────────────────────────────────────┘

  扰动输入参数S0:

    V_0     = solve_pde(S0=100, σ=0.2) = 10.5
    V_plus  = solve_pde(S0=101, σ=0.2) = 10.52
    V_minus = solve_pde(S0=99,  σ=0.2) = 10.48

  Gamma = (V_plus - 2×V_0 + V_minus) / eps²
        = (10.52 - 2×10.5 + 10.48) / (1²)
        = 0.0  ← 这个例子中太小看不出来

  实际结果（真实测试）:
    Gamma = 0.0177  ✅

  优点:
    - 简单直观
    - 正确性保证（直接扰动参数空间）

  缺点:
    - 需要3次PDE求解

  总结
═══════════════════════════════════════════════════════════════════════════════

  问题根源:
    线性插值的二阶导数 = 0

  修复方案:
    放弃AAD，改用网格有限差分

  为什么网格FD有效:
    V_grid本身包含S依赖性，V[i+1]-V[i]反映∂V/∂S

  推荐使用:
    - 生产环境: Bumping (简单可靠)
    - 研究环境: Edge-Pushing修复版 (展示混合方法)
    - 避免使用: Edge-Pushing原版 (Gamma=0)
