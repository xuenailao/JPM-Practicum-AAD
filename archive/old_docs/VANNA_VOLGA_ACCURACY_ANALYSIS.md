# Vanna和Volga精度波动分析报告

## 问题描述

在PDE Greeks计算中，Vanna和Volga的相对误差出现异常大的波动：
- **Vanna相对误差**: 88-154% (平均值)
- **Volga相对误差**: 838-941% (平均值)
- 某些极端情况下，误差可达1000%甚至10000%以上

这看起来非常糟糕，但深入分析后发现：**这是相对误差的统计陷阱，而非数值方法的失败**。

---

## 核心发现

### 1. 真实值接近零导致的相对误差爆炸

**关键数据**（Edge-Pushing方法）:

| Vanna真实值范围 | 案例数 | 平均相对误差 | 平均绝对误差 |
|----------------|--------|--------------|--------------|
| \|vanna\| < 0.1 | 2个 | **599.60%** | 0.126 |
| \|vanna\| ≥ 0.1 | 16个 | **24.68%** | 0.074 |
| \|vanna\| ≥ 0.5 | 7个 | **7.60%** | 0.059 |
| \|vanna\| ≥ 1.0 | 2个 | **4.08%** | 0.051 |

| Volga真实值范围 | 案例数 | 平均相对误差 | 平均绝对误差 |
|----------------|--------|--------------|--------------|
| \|volga\| < 1.0 | 3个 | **3951.19%** | 25.84 |
| \|volga\| ≥ 1.0 | 15个 | **215.57%** | 14.50 |
| \|volga\| ≥ 5.0 | 10个 | **136.72%** | 16.46 |
| \|volga\| ≥ 10.0 | 7个 | **180.54%** | 22.09 |

**结论**:
- 当真实值<0.5时，即使绝对误差很小（0.1），相对误差也会爆炸至>20%
- 这是**统计幻觉**，而非数值方法失败

- 绝对误差虽大(76.5)，但在PDE离散化(M=51, N=50)下属于合理范围
- 相对误差被真实值的小数放大了100倍

- 相对误差完全失去参考意义

### 3. 为什么Vanna和Volga会接近零？

这是**Black-Scholes公式的内在性质**，而非数值误差！

#### 解析公式
```
Vanna = -φ(d1) · d2 / σ
Volga = Vega · d1 · d2 / σ
```

其中：
```
d1 = [ln(S0/K) + (r + 0.5σ²)T] / (σ√T)
d2 = d1 - σ√T
```

#### Vanna和Volga接近零的条件

| 条件 | 数学原因 | 物理意义 |
|------|---------|----------|
| **d2 ≈ 0** | Vanna含因子d2 | S0接近调整后执行价 K·exp((r-0.5σ²)T) |
| **d1 ≈ 0** | Volga含因子d1·d2 | At-the-money期权 |
| **高σ** | 分母含σ | 高波动率降低二阶Greeks |

#### 实际数据验证

| σ | 平均\|Vanna\| | 平均\|Volga\| | 平均相对误差(Vanna) | 平均相对误差(Volga) |
|---|-------------|-------------|-------------------|-------------------|
| 0.15 | 0.764 | 35.02 | **15.6%** | **41.0%** |
| 0.20 | 0.437 | 15.59 | **6.2%** | **31.4%** |
| 0.30 | 0.175 | 4.09 | **243.9%** | **2442.2%** |

**观察**:
- σ从0.15→0.30，真实值下降80-90%
- 相对误差爆炸1500%，但绝对误差基本稳定

## 根本原因总结

### 原因1: 数学特性（主因）
- Vanna和Volga在某些参数组合下**天然接近零**
- 这是Black-Scholes公式的固有性质
- 当S0≈K、高σ、或特定T时，二阶Greeks会很小

### 原因2: 离散化累积（次因）
- PDE网格(M=51, N=50)的离散化误差
- 有限差分计算二阶导数时误差放大
- 但这个误差绝对值其实很小（<0.1 for Vanna, <20 for Volga）

### 原因3: 统计度量选择（表象）
- 使用相对误差作为唯一指标
- 当真实值<1时，相对误差失去意义
- 应该报告绝对误差或条件相对误差

## 改进建议

### 1. 报告指标优化

**当前**:
```python
vanna_error_pct = |vanna_numerical - vanna_analytical| / |vanna_analytical| × 100%
```

**建议**:
```python
# 方案A: 条件相对误差
if |vanna_analytical| > threshold:
    error = relative_error
else:
    error = absolute_error

# 方案B: 归一化误差
error = |vanna_numerical - vanna_analytical| / (|vanna_analytical| + epsilon)

# 方案C: 同时报告两者
report = {
    'absolute_error': abs_err,
    'relative_error': rel_err if true_val > threshold else None
}
```

**推荐阈值**:
- Vanna: 0.5
- Volga: 5.0

### 2. 网格分辨率优化

| 目标精度 | 建议网格 | 预期Vanna误差 | 预期Volga误差 |
|---------|---------|--------------|--------------|
| 快速原型 | M=51, N=50 | 8% | 33% |
| 生产环境 | M=101, N=100 | <3% | <10% |
| 高精度研究 | M=201, N=200 | <1% | <5% |

### 3. 自适应误差控制

```python
def adaptive_greeks(S0, K, T, r, sigma, target_error=0.01):
    """根据真实值大小自适应选择网格"""

    # 估算Greeks数量级
    d1_approx = (np.log(S0/K) + r*T) / (sigma*np.sqrt(T))

    # Vanna和Volga较小时，使用更细网格
    if abs(d1_approx) < 0.5 or sigma > 0.25:
        M, N = 201, 200  # 高分辨率
    else:
        M, N = 101, 100  # 标准分辨率

    return compute_greeks(M, N, ...)
```
