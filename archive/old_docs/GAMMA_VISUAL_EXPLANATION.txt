  1. PDE求解器输出的价格网格
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  股价网格 S_grid:
  
     0      50     100    150    200    250
     ├──────┼──────┼──────┼──────┼──────┤
     S[0]  S[1]  S[2]  S[3]  S[4]  S[5]

  对应的期权价格 V_grid:

     0.0    4.2   10.5   18.3   27.1   36.5
     ├──────┼──────┼──────┼──────┼──────┤
    V[0]  V[1]  V[2]  V[3]  V[4]  V[5]

  关键洞察：
  • V[i] = V(S=S[i], t=0, σ)
  • 不同的 i 对应不同的股价 S[i]
  • 因此 V[i] 本身就包含了 S 的依赖性！


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  2. 修复前：线性插值（WRONG）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  目标：计算 V(S0=105)

  Step 1: 找到插值区间
  
     100         105         150
      •───────────×───────────•
     V[2]       S0          V[3]
    10.5                   18.3

  Step 2: 线性插值
  
     w = (105 - 100) / (150 - 100) = 0.1
     
     V(105) = (1 - 0.1) × 10.5  +  0.1 × 18.3
            =   0.9 × 10.5      +  0.1 × 18.3
            =   9.45            +  1.83
            =  11.28

  Step 3: 计算Gamma（失败！）
  
     V(S0) = 0.9 × V[2] + 0.1 × V[3]
           = 常数 × V[2] + 常数 × V[3]
     
     这是一个关于 S0 的线性函数！
     
     图形表示：
     
     V(S)
      │
      │         ╱  线性函数
      │       ╱    (直线)
      │     ╱
      │   ╱
      │ ╱
      └───────────────────> S
          100  105  150
     
     直线的二阶导数 = 0
     
     ∴ Gamma = ∂²V/∂S² = 0  ❌❌❌


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  3. 修复后：网格有限差分（CORRECT）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  目标：计算 Gamma at S0=105

  Step 1: 找到最近的网格点
  
     50      100     150     200
     •────────•───────•───────•
    V[1]    V[2]    V[3]    V[4]
    4.2     10.5    18.3    27.1
            ↑
          最近点
          (idx=2)

  Step 2: 三点模板
  
              V[idx-1]    V[idx]      V[idx+1]
                 •          •            •
                V[1]       V[2]         V[3]
                4.2        10.5         18.3
                 │          │            │
                 └──── dS=50 ────┘
                            └──── dS=50 ────┘

  Step 3: 二阶中心差分公式
  
     Gamma = [V[idx+1] - 2×V[idx] + V[idx-1]] / dS²
     
           = [18.3 - 2×10.5 + 4.2] / (50²)
           
           = [18.3 - 21.0 + 4.2] / 2500
           
           = 1.5 / 2500
           
           = 0.0006  ✅✅✅

  为什么这个公式正确？
  
  泰勒展开解释：
  
     V(S+h) = V(S) + h·V'(S) + (h²/2)·V''(S) + O(h³)
     V(S-h) = V(S) - h·V'(S) + (h²/2)·V''(S) + O(h³)
     
     相加：
     V(S+h) + V(S-h) = 2V(S) + h²·V''(S) + O(h⁴)
     
     求解：
     V''(S) = [V(S+h) - 2V(S) + V(S-h)] / h² + O(h²)

  Delta视角解释：
  
     Delta_right = [V(S+dS) - V(S)] / dS
                 = [18.3 - 10.5] / 50
                 = 0.156
     
     Delta_left = [V(S) - V(S-dS)] / dS
                = [10.5 - 4.2] / 50
                = 0.126
     
     Gamma = (Delta_right - Delta_left) / dS
           = (0.156 - 0.126) / 50
           = 0.0006
     
     直观意义：Gamma 衡量 Delta 的变化率

  5. 与Bumping方法的直观对比

  7. 关键结论
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ 问题根源:
     线性插值 price = (1-w)×V[i] + w×V[i+1]
     → 关于S0是线性的
     → 二阶导数为0

  ✅ 修复方案:
     不用插值，直接在网格上用有限差分
     Gamma = [V[i+1] - 2V[i] + V[i-1]] / dS²

  ✅ 为什么有效:
     V_grid本身包含S依赖性
     V[i+1] - V[i] 反映 ∂V/∂S
     二阶差分反映 ∂²V/∂S²

  ✅ 混合方法:
     Vega: AAD (σ在计算图中)
     Gamma: 网格FD (S0不在图中)
     
  ✅ 实践建议:
     生产环境: 用Bumping (简单可靠)
     研究环境: 用Edge-Pushing Fixed (1次PDE)
     避免使用: Edge-Pushing原版 (Gamma=0)
