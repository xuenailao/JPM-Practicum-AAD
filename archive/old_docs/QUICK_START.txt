--------------------------------------------------------------------------------
🔍 测试内容
--------------------------------------------------------------------------------

5种方法:
  1. Analytical      - BSM解析公式 (基准)
  2. Bumping         - 有限差分 (5次PDE)
  3. AAD + Bumping   - 混合方法 (5次PDE)
  4. Double AAD      - 双重AAD (1次PDE)
  5. Edge-Pushing    - 边推算法 (1次PDE) ⭐推荐

测试指标:
  ✓ 速度 (ms)
  ✓ 精度 (vs 解析解误差%)
  ✓ Greeks: Delta, Gamma, Vega, Vanna, Volga
  ✓ 计算图: 节点/边数量 (AAD方法)

--------------------------------------------------------------------------------
📊 预期结果 (M=51)
--------------------------------------------------------------------------------

速度:
  Analytical:    0.5 ms   (基准)
  Bumping:       85 ms    (5次PDE)
  Edge-Pushing:  75 ms    (1次PDE, 最快PDE方法)

精度:
  Edge-Pushing:  Gamma < 1%, Volga < 10%  ⭐最准确

计算图:
  Edge-Pushing:  ~12,750节点, ~38,250边 (M=51时)
