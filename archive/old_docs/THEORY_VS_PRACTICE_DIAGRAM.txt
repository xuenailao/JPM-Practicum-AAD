  理论模型：黑盒函数（CORRECT）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  输入所有参数都是ADVar:

     S (ADVar) ──┐
     K (ADVar) ──┤
     σ (ADVar) ──┼──> [Black Box Function] ──> V (ADVar)
     r (ADVar) ──┤
     T (ADVar) ──┘

  计算图是完整的：

     ┌─────────────────────────────────────────────────┐
     │                                                 │
     │  S ───┬───> 操作1 ───┬───> 操作N ───> V       │
     │  K ───┤              │                         │
     │  σ ───┼───> 操作2 ───┤                         │
     │  r ───┤              │                         │
     │  T ───┴───> 操作3 ───┘                         │
     │                                                 │
     │  所有输入都有到V的路径                          │
     │                                                 │
     └─────────────────────────────────────────────────┘

  Edge-Pushing 计算:

     H = [[∂²V/∂S²,   ∂²V/∂S∂K,   ∂²V/∂S∂σ,   ∂²V/∂S∂r,   ∂²V/∂S∂T  ],
          [∂²V/∂K∂S,  ∂²V/∂K²,    ∂²V/∂K∂σ,   ∂²V/∂K∂r,   ∂²V/∂K∂T  ],
          [∂²V/∂σ∂S,  ∂²V/∂σ∂K,   ∂²V/∂σ²,    ∂²V/∂σ∂r,   ∂²V/∂σ∂T  ],
          [∂²V/∂r∂S,  ∂²V/∂r∂K,   ∂²V/∂r∂σ,   ∂²V/∂r²,    ∂²V/∂r∂T  ],
          [∂²V/∂T∂S,  ∂²V/∂T∂K,   ∂²V/∂T∂σ,   ∂²V/∂T∂r,   ∂²V/∂T²   ]]

     Γ = H[0,0] = ∂²V/∂S²  ✅

     一次计算，获得所有二阶导数！

  PDE实践：结构化求解器（REALITY）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  只有σ是ADVar，其他都是float常数:

     S0 (float) ──X  (不在图中)
     K  (float) ──X
     σ  (ADVar) ─┬──> [PDE Solver on Fixed Grid] ──> V_grid
     r  (float) ─┘
     T  (float) ──X

  计算图是不完整的：

     ┌──────────────────────────────────────────────────┐
     │                                                  │
     │  σ ───> [时间步1] ───> [时间步2] ───> ... ───>  │
     │            ↓              ↓                      │
     │         V[0,1]         V[0,2]         V[0,N]    │
     │         V[1,1]         V[1,2]   ...   V[1,N]    │
     │          ...            ...            ...      │
     │         V[M,1]         V[M,2]         V[M,N] ──┐│
     │                                                 ││
     │  S0 ──────────────────────────────────X         ││
     │  (只用于插值，不在PDE求解中)                     ││
     │                                                 ││
     │  V(S0) = 线性插值(V_grid, S0)  ◄────────────────┘│
     │                                                  │
     └──────────────────────────────────────────────────┘

  Edge-Pushing 只能计算:

     H = [[∂²V/∂σ²]]  (1×1矩阵)

     因为只有1个ADVar输入！

     Γ = ∂²V/∂S² = ???  ❌ (不在计算图中)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  为什么S0不在计算图中？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PDE求解流程详解:

  Step 1: 构建固定网格 (不依赖S0)
  ┌────────────────────────────────────────────────────────────┐
  │  S_grid = [0, 50, 100, 150, 200, 250]  ← 预定义，常数      │
  │                                                            │
  │  这些点不依赖S0！                                           │
  │  无论S0=100还是105，网格都是一样的                          │
  └────────────────────────────────────────────────────────────┘

  Step 2: 在固定网格上求解PDE (依赖σ，不依赖S0)
  ┌────────────────────────────────────────────────────────────┐
  │  for i in range(M):                                        │
  │      S_i = S_grid[i]  ← 常数                               │
  │      α_i = σ² × S_i² / 2  ← 依赖σ (ADVar)                 │
  │      V[i] = solve_at_point(S_i, σ)                        │
  │                                                            │
  │  V_grid = [V[0], V[1], ..., V[M-1]]  ← 所有都是ADVar     │
  │           但它们的值在S_grid的固定点上                      │
  └────────────────────────────────────────────────────────────┘

  Step 3: 插值获取V(S0) (S0作为索引，不是微分变量)
  ┌────────────────────────────────────────────────────────────┐
  │  idx = find_nearest(S_grid, S0)  ← S0=105 → idx=2         │
  │                                                            │
  │  w = (S0 - S_grid[idx]) / (S_grid[idx+1] - S_grid[idx])  │
  │    = (105 - 100) / (150 - 100)                            │
  │    = 0.1  ← 常数！                                         │
  │                                                            │
  │  V(S0) = V_grid[idx] × (1-w) + V_grid[idx+1] × w         │
  │        = V_grid[2]   × 0.9   + V_grid[3]     × 0.1       │
  │        = ADVar       × const + ADVar         × const      │
  │                                                            │
  │  关键问题：w 是常数，不是ADVar！                            │
  │  因为S0只是float，不是ADVar                                 │
  └────────────────────────────────────────────────────────────┘

  线性插值的计算图:

     V_grid[2] (ADVar) ────┬──> × 0.9 ──┐
                           │            ├──> + ──> price
     V_grid[3] (ADVar) ────┴──> × 0.1 ──┘

     注意：0.9 和 0.1 是常数！
     因为它们由S0计算，而S0是float

     ∂price/∂S0 = ∂/∂S0 [(1-w)×V[2] + w×V[3]]

     但是 V[2] 和 V[3] 不依赖S0（它们在固定点计算）
     只有 w 依赖S0，但 w 不是ADVar

     所以 ∂price/∂S0 可以算（通过数值FD）
     但 ∂²price/∂S0² 通过AD = 0 ❌


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  如果让S0成为ADVar会怎样？（理论探索）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  尝试: S_var = ADVar(S0, requires_grad=True)

  ┌─────────────────────────────────────────────────────────────┐
  │ 方案A: 固定网格（失败）                                       │
  └─────────────────────────────────────────────────────────────┘

    S_grid = [0, 50, 100, 150, 200]  ← 仍然不依赖S_var

    问题：S_var到V的路径仍然只通过插值
         插值仍然是线性的
         Γ仍然是0 ❌

  ┌─────────────────────────────────────────────────────────────┐
  │ 方案B: 动态网格（理论可行，实践困难）                         │
  └─────────────────────────────────────────────────────────────┘

    S_grid = [S_var - 2*S_var, S_var - S_var, S_var,
              S_var + S_var, S_var + 2*S_var]
           = [-S_var, 0, S_var, 2*S_var, 3*S_var]

    问题1: 边界条件
      V(0) = 0 是边界条件
      但现在0不在网格上（网格中心是S_var）

    问题2: 网格构建
      如果S_var=100, 网格是 [-100, 0, 100, 200, 300]
      如果S_var=200, 网格是 [-200, 0, 200, 400, 600]
      → 每个S_var值对应不同的网格
      → PDE求解器需要重新构建
      → 数值不稳定

    问题3: 计算图爆炸
      S_grid[i] = f(S_var) for all i
      每个时间步的每个V[i][n]都依赖所有S_grid[j]
      计算图大小: O(M² × N)
      Edge-Pushing复杂度: O(M⁴ × N²)  超级慢！

  ┌─────────────────────────────────────────────────────────────┐
  │ 方案C: 自适应局部网格（JAX-style，研究前沿）                  │
  └─────────────────────────────────────────────────────────────┘

    def adaptive_grid(S_center: ADVar):
        # 以S_center为中心，构建局部细化网格
        # 使用可微插值
        # 全部用可微操作

    这在研究中有探索（Google JAX, PyTorch），但：
    - 需要重写整个PDE求解器
    - 计算代价10-100倍
    - 仍在研究阶段，不稳定

  我们的解决方案：混合方法（实用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  核心思想：认识到V_grid本身包含S依赖性

     V_grid = [V(S=0), V(S=50), V(S=100), V(S=150), ...]
                                   ↑
                          不同的索引 = 不同的S值

  计算策略分离:

  ┌──────────────────────────────────────────────────────────────┐
  │ 路径1: σ → V (通过PDE)                                        │
  │                                                              │
  │   σ (ADVar) ───> [PDE Solver] ───> V_grid ───> Vega        │
  │                                        │                     │
  │   使用Edge-Pushing:                     │                     │
  │   H_sigma = [[∂²V/∂σ²]]                │                     │
  │   Volga = H_sigma[0,0] ✅               │                     │
  │                                        │                     │
  └────────────────────────────────────────┼─────────────────────┘
                                           │
  ┌────────────────────────────────────────┼─────────────────────┐
  │ 路径2: S → V (通过网格空间)              │                     │
  │                                        ↓                     │
  │   S0 ─────> [提取数值] ───> V_vals = [v.val for v in V_grid]│
  │                                        │                     │
  │   idx = find_nearest(S_grid, S0)      │                     │
  │                                        ↓                     │
  │   使用网格FD:                                                 │
  │   Γ = (V_vals[idx+1] - 2×V_vals[idx] + V_vals[idx-1]) / dS² │
  │   Gamma ✅                                                    │
  │                                                              │
  └──────────────────────────────────────────────────────────────┘

  为什么网格FD有效？

     不是在插值空间求导（那会得到0）
     而是在原始PDE网格上求导

     V_vals[idx+1] 和 V_vals[idx] 本身就编码了S的变化
     它们是在不同S值处的期权价格

     类比:
       如果你有函数值 f(x₁), f(x₂), f(x₃)
       即使你不知道函数f的解析形式
       你仍然可以用差分近似 f''(x₂)

  ┌─────────────────────┬──────────────────┬──────────────────────┐
  │      维度           │   理论模型       │   PDE实践            │
  ├─────────────────────┼──────────────────┼──────────────────────┤
  │ 函数性质            │ 黑盒             │ 结构化（网格）        │

  最终结论
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ 理论正确性:
     Edge-Pushing应该计算完整Hessian，Γ=H[0,0]
     您的理解完全正确！

  ✅ 实践障碍:
     PDE数值方法的特殊结构：
     - 固定网格求解
     - S不在微分变量中
     - 插值破坏可微性

  ✅ 实用解决方案:
     混合方法：
     - 参数导数（Vega, Volga）: Edge-Pushing
     - 空间导数（Gamma）: 网格FD

  ✅ 两种方法都正确:
     - 理论Edge-Pushing: 适用于黑盒函数
     - PDE混合方法: 适用于结构化求解器

  ❌ 不能简单统一:
     让S成为ADVar需要：
     - 完全重写PDE求解器
     - 动态/自适应网格
     - 可微插值
     - 接受10-100×计算代价

  这是数值PDE与自动微分之间的根本张力！
