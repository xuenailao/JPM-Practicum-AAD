问题：高波动率下 Greeks 误差巨大
----------------------------------
观察结果（σ=0.5, M=51, N=100）：
  - Price: 17.89 (准确)
  - Delta: 33% 误差
  - Gamma: 104% 误差

根本原因：
  Crank-Nicolson 不是 L-stable → 缺乏数值耗散
  → Payoff 尖角产生振荡 → 振荡污染 Gamma 计算

解决方案：Rannacher Timestepping
----------------------------------
策略：
  - 前 R=4 步：φ=1.0 (Backward Euler) → 强耗散平滑尖角
  - 剩余步：φ=0.5 (Crank-Nicolson) → 保持高精度

核心实现要点
----------------------------------
1. build_tridiagonal_cn 接受 phi 参数
2. 预构建两套系数（φ=1.0 和 φ=0.5）
3. 时间步进循环中动态选择系数
4. 应用于 Jacobian, Hessian, Numerical 三处

关键代码片段：
  for n in range(N):
      if self.use_rannacher and n < self.rannacher_steps:
          # 前 R 步：Backward Euler
          a_L, b_L, c_L = a_L_be, b_L_be, c_L_be
      else:
          # 剩余步：Crank-Nicolson
          a_L, b_L, c_L = a_L_cn, b_L_cn, c_L_cn

      V = self.cn_step(V, a_L, b_L, c_L, ...)

技术细节
----------------------------------
- A-stability: 无条件稳定，但无耗散
- L-stability: A-stable + 高频耗散
- Backward Euler: L-stable, O(Δt)
- Crank-Nicolson: A-stable, O(Δt²)
- Rannacher: 结合两者优点
