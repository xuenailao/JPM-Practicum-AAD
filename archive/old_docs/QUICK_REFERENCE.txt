 KEY INSIGHT: GAMMA = 0 PROBLEM (SOLVED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem:
  Linear interpolation has zero second derivative
  price = (1-w) × V[i] + w × V[i+1]
  ∂²price/∂S² = 0  ❌

Solution:
  Use grid-based finite difference
  gamma = [V[i+1] - 2×V[i] + V[i-1]] / dS²  ✅

Why it works:
  V_grid = [V(S=0), V(S=50), V(S=100), ...]
  Different indices = different S values
  Grid FD captures ∂²V/∂S² correctly

  Volga  = ∂²V/∂σ²    (Vega sensitivity to volatility)

  Parameter Derivatives (σ):
    - Vega  → AAD backward pass  ✅

    - Delta → Grid FD            ✅

    - Vanna → FD on Delta        ✅

 KEY MATHEMATICAL FORMULAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Black-Scholes PDE:
  ∂V/∂t + (1/2)σ²S²∂²V/∂S² + rS∂V/∂S - rV = 0

Central Difference (Delta):
  ∂V/∂S ≈ [V(S+h) - V(S-h)] / (2h)

Three-Point Stencil (Gamma):
  ∂²V/∂S² ≈ [V(S+h) - 2V(S) + V(S-h)] / h²

Finite Difference (Vanna):
  ∂²V/∂S∂σ ≈ [Delta(σ+ε) - Delta(σ-ε)] / (2ε)
