## 1. 实施目标

按照五层治理方案的**方案1A（最高优先级）**：

> **ν=σ² 参数化** - 消除扩散系数中的二次非线性，为未来优化奠定基础

**理论动机：**
- Black-Scholes PDE中σ以二次方出现：∂V/∂t + (1/2)σ²S²∂²V/∂S² + ... = 0
- 令 ν = σ²，使扩散系数α = (1/2)νS²/ΔS² 对ν线性
- 预期简化反向传播路径，降低二阶导数误差

### 2.2 关键实现

**前向计算（ν作为独立变量）：**

```python
# 使用 ν = σ² 作为独立变量
nu_val = sigma_val ** 2
nu_var = ADVar(nu_val, requires_grad=True, name="nu")

# 扩散系数构建（对ν线性！）
alpha_i = (nu_var * S_i_var * S_i_var / ADVar(2.0)) / dS_sq
#         ^^^^^^
#         直接使用ν，无需σ²运算
```

**反向传播（链式法则还原Greeks）：**

```python
# 一阶导数：Vega
dV_dnu = nu_var.adj  # ∂V/∂ν
vega = dV_dnu * 2 * sigma_val  # ∂V/∂σ = (∂V/∂ν) · (∂ν/∂σ) = (∂V/∂ν) · 2σ

# 二阶导数：Volga
d2V_dnu2 = hessian_nu[1, 1]  # ∂²V/∂ν²
volga = 4 * sigma_val**2 * d2V_dnu2 + 2 * dV_dnu
#       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
#       链式法则：∂²V/∂σ² = 4σ²(∂²V/∂ν²) + 2(∂V/∂ν)
```

### 2.3 计算图对比

**σ-参数化（原始方法）：**
```
σ → [square] → σ² → [multiply] → α → ... → V
    ↑
    引入二次非线性
```

**ν-参数化（新方法）：**
```
ν → [multiply] → α → ... → V
    ↑
    线性关系
```

路径更短，理论上应减少误差传播。

## 4. 结果分析

### 4.1 为什么结果相同？

**原因1：求解相同的PDE**

两种方法求解完全相同的数值PDE：
```
∂V/∂t + (1/2)ν S² ∂²V/∂S² + rS∂V/∂S - rV = 0
```

无论我们称之为σ²还是ν，数值解 V(S,t;ν) 完全相同。

**原因2：AAD链式法则是精确的**

```
σ-参数化路径：
  ∂V/∂σ = (∂V/∂α) · (∂α/∂σ²) · (∂σ²/∂σ)

ν-参数化路径：
  ∂V/∂σ = (∂V/∂α) · (∂α/∂ν) · (∂ν/∂σ)

数学上等价：
  (∂V/∂α) · (∂α/∂σ²) · 2σ = (∂V/∂α) · (∂α/∂ν) · 2σ

因为 ∂α/∂σ² = ∂α/∂ν (ν ≡ σ²)
```

**原因3：无数值近似误差**

AAD通过计算图进行**符号微分**，链式法则应用是**精确的**，没有有限差分近似误差。

### 4.2 预期优势为何未体现？

**理论预期：** 更短的计算图路径 → 更少的误差累积

**实际情况：** AAD的链式法则是精确的，不存在路径长度导致的误差累积

**误差来源：** PDE离散化截断误差（与计算图无关）
- 空间离散化：O(ΔS²)
- 时间离散化：O(Δt²)
- 这些误差在两种参数化中完全相同

### 4.3 何时ν-参数化会有优势？

1. **非AAD有限差分方案**
   - 如果使用有限差分计算导数，路径长度会影响误差累积
   - ν-参数化可能减少差分次数

2. **自定义算子优化**
   - 如果为三对角求解器实现自定义AAD原语（方案1B）
   - 可能在ν-参数化下更容易优化

3. **迭代求解器**
   - 在非线性迭代中，σ²的二次项可能影响收敛性
   - ν-参数化可能改善收敛特性

4. **数值稳定性敏感场景**
   - 极端参数下（σ很大/很小），ν作为独立变量可能更稳定

## 6. 技术附录

### 6.1 Volga链式法则推导

给定 ν = σ²，求 ∂²V/∂σ²：

**一阶导数：**
```
∂V/∂σ = (∂V/∂ν) · (∂ν/∂σ) = (∂V/∂ν) · 2σ
```

**二阶导数（完整推导）：**
```
∂²V/∂σ² = ∂/∂σ [(∂V/∂ν) · 2σ]

应用乘积法则：
= [∂/∂σ(∂V/∂ν)] · 2σ + (∂V/∂ν) · 2

对第一项应用链式法则：
∂/∂σ(∂V/∂ν) = (∂²V/∂ν²) · (∂ν/∂σ) = (∂²V/∂ν²) · 2σ

因此：
∂²V/∂σ² = (∂²V/∂ν²) · 2σ · 2σ + (∂V/∂ν) · 2
         = 4σ² (∂²V/∂ν²) + 2(∂V/∂ν)
```

**代码实现：**
```python
volga = 4 * sigma_val**2 * d2V_dnu2 + 2 * dV_dnu
```
