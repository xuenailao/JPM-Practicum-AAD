## 📊 方法1：变量变换PDE

### 实现要点

**坐标变换**：
```
x = ln(S/K)
τ = σ²(T-t)/2
```

**变换后的PDE**：
```
∂V/∂τ = ∂²V/∂x² + b(σ)∂V/∂x + c(σ)V

其中：
  b(σ) = 2r/σ² - 1
  c(σ) = -2r/σ²
```

**关键优势**：扩散系数 = 1 (常数)

## 📊 方法2：Adjoint PDE

### 实现要点

**两步求解**：

1. **Forward PDE**：
   ```
   ∂V/∂t + L_BS[V] = 0
   → 得到 V 和 Γ = ∂²V/∂S²
   ```

2. **Adjoint PDE**：
   ```
   ∂Vega/∂t + L_BS[Vega] = -σS²Γ
                            ^^^^^^^^
                            源项
   ```

### 测试结果 (Grid: M=151, N=150)

| σ | BS Vega | Adjoint Vega | Error | Status |
|---|---------|--------------|-------|--------|
| 0.15 | 36.703 | **-36.513** | 199.48% | ❌ |
| 0.18 | 37.285 | **-35.448** | 195.07% | ❌ |
| 0.20 | 37.524 | **-32.630** | 186.96% | ❌ |
| 0.22 | 37.689 | **-27.850** | 173.90% | ❌ |
| 0.25 | 37.842 | **-17.948** | 147.43% | ❌ |
| 0.30 | 37.943 | **+0.033** | 99.91% | ❌ |

### Vega趋势分析

```
σ: 0.15 → 0.18  Vega: -36.51 → -35.45 ↗ ✅ (趋势对)
σ: 0.18 → 0.20  Vega: -35.45 → -32.63 ↗ ✅
σ: 0.20 → 0.22  Vega: -32.63 → -27.85 ↗ ✅
σ: 0.22 → 0.25  Vega: -27.85 → -17.95 ↗ ✅
σ: 0.25 → 0.30  Vega: -17.95 → 0.03 ↗ ✅
```

**趋势完全正确！但绝对值全错（符号相反）**

### 问题诊断

❌ **主要问题**：
- Vega符号错误（负值）
- 绝对值误差巨大（147-199%）
- 趋势正确说明方向对了

🔍 **可能原因**：
1. **源项符号错误**：
   - 当前：`Source = -σS²Γ`
   - 可能应该：`Source = +σS²Γ`
   - 需要重新推导

2. **边界条件问题**：
   - Adjoint PDE的边界条件不明确
   - Terminal condition: Vega(S,T) = 0 可能不对

3. **时间方向**：
   - Forward和Adjoint的时间步进方向可能需要调整

### 计算成本

- 时间：~32秒/solve
- 相比Forward PDE：2×（一次forward + 一次adjoint）
- 存储：需要保存所有时间步的Γ

## 📝 技术总结

### 关键洞察

1. **数值阻尼的根源**：
   - CN格式：α ∝ σ²
   - 高σ时α很大 → 数值阻尼
   - 解决：变量变换使α=1

2. **为什么变换有效**：
   - σ从扩散项移到drift项
   - 线性依赖 vs 二次依赖
   - 数值稳定性本质提升

3. **为什么Adjoint有问题**：
   - Forward PDE本身有误差
   - Γ的误差传播到Source
   - 符号问题说明推导可能有误
