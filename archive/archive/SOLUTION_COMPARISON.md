# Vega问题解决方案对比

## 🎯 核心问题

**当前CN格式**：扩散系数 α = (σ²S²/2)/dS² ∝ σ²

```
σ增大 → α增大 → 数值阻尼 → Price错误 → Vega错误
```

---

## 方案1: 变量变换 (Variable Transformation)

### 核心公式

**变换前（原始BS PDE）**：
```
∂V/∂t + (σ²S²/2)·∂²V/∂S² + rS·∂V/∂S - rV = 0
         ^^^^^^^^
         问题根源：σ²在扩散项
```

**变换后**：
```
x = ln(S/K)
τ = σ²(T-t)/2

∂V/∂τ = ∂²V/∂x² + [2r/σ² - 1]·∂V/∂x - [2r/σ²]·V
        ^^^^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
        常数=1     σ只在这里（线性项）
```

### 视觉对比

```
原始空间 (S, t):
  ┌─────────────────────┐
  │ σ²在扩散系数里       │
  │ 高σ → 大系数 → 阻尼  │
  │                     │
  │ α(σ) = σ²·S²/(2dS²) │
  │                     │
  │ σ=0.3: α = 112.5   │ ← 不稳定！
  └─────────────────────┘

变换空间 (x, τ):
  ┌─────────────────────┐
  │ 扩散系数 = 1        │
  │ σ只在drift/reaction │
  │                     │
  │ α = 1               │ ← 稳定！
  │                     │
  │ 所有σ都一样        │
  └─────────────────────┘
```

### 为什么解决问题

**数值稳定性分析**：

| σ | 原始α | 变换后α | 稳定性 |
|---|------|---------|--------|
| 0.15 | 28.1 | **1.0** | ✅ 稳定 |
| 0.20 | 50.0 | **1.0** | ✅ 稳定 |
| 0.30 | 112.5 | **1.0** | ✅ 稳定 |
| 0.40 | 200.0 | **1.0** | ✅ 稳定 |

**关键**：σ的影响从二次（σ²在扩散）变为线性（σ在drift）

## 方案2: Adjoint PDE

### 核心公式

**Forward PDE (求V和Γ)**：
```
∂V/∂t + L_BS[V] = 0
V(S,T) = Payoff(S)

→ 得到 V(S,t) 和 Γ(S,t) = ∂²V/∂S²
```

**Adjoint PDE (直接求Vega)**：
```
∂Vega/∂t + L_BS[Vega] = -σS²·Γ(S,t)
                         ^^^^^^^^^^^
                         源项！
Vega(S,T) = 0

→ 直接得到 Vega(S,t)
```

### 视觉对比

```
有限差分方法 (当前):

  V(σ-ε) ──┐
           ├─→ [V(σ+ε) - V(σ-ε)]/(2ε) = Vega
  V(σ+ε) ──┘
           ↑
           问题：高σ时V本身不准


Adjoint方法:

  Forward:  V(σ) ──→ Γ(σ) ──┐
                             ├─→ Source = -σS²Γ
  Adjoint:  Vega ←──────────┘
            ↑
            直接求解，不通过有限差分！
```

### 为什么解决问题

**关键洞察**：

1. **绕过有限差分**：
   ```
   FD:      Vega ≈ ΔV/Δσ     ← 如果V错，Vega必错
   Adjoint: Vega = solve PDE  ← V的误差不直接传播
   ```

2. **源项精确**：
   ```
   Source = -σS²Γ

   即使Γ有小误差ε_Γ，对Vega的影响是O(ε_Γ)
   但FD中，V的误差ε_V对Vega的影响是O(ε_V/ε)，放大！
   ```

3. **数学严格性**：
   ```
   Adjoint是从PDE对σ求导严格推导出来的
   不是数值近似，是精确关系
   ```

## 实现难度对比

### 变量变换

**需要修改**：
```python
# 1. 网格定义
x_grid = linspace(-L, L, M)  # 对数价格
tau_max = sigma^2 * T / 2    # 方差时间

# 2. 系数计算
alpha = 1  # 常数！
b = 2r/sigma^2 - 1
c = -2r/sigma^2

# 3. 边界条件
V(x, 0) = K * max(exp(x) - 1, 0)

# 4. AAD路径
sigma_var影响：tau, b, c
```

**保持不变**：
- CN格式框架
- 三对角求解器
- 时间步进逻辑

### Adjoint PDE

**需要修改**：
```python
# 1. Forward solve
V, Gamma = forward_solve(sigma)
# 保存所有时间步的Gamma

# 2. 带源项的PDE求解器
def cn_step_with_source(V, Source, ...):
    RHS = R_B @ V + dt * Source  # 添加源项
    V_new = solve(L_B, RHS)
    return V_new

# 3. Adjoint solve
Vega = adjoint_solve(sigma, Gamma_history)

# 4. 边界条件
Vega(S, T) = 0  # Terminal为0
```

**新增复杂度**：
- 存储Gamma历史
- 源项处理
- 两次PDE求解
