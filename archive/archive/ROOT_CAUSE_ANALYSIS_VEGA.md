# PDE Vega失败的根本原因分析

## 🎯 问题陈述

**观察到的异常**：
- **解析解 (Black-Scholes)**: Vega随σ**增大**而增大 ✅ (正确)
- **PDE求解器**: Vega随σ**增大**而**减小** ❌ (错误)

**具体数据** (M=101×100):

| σ | BS Vega | PDE Vega | 误差 |
|---|---------|----------|------|
| 0.15 | 36.70 | 36.64 | 0.18% ✅ |
| 0.20 | 37.52 | 32.77 | 12.68% ⚠️ |
| 0.25 | 37.84 | 18.17 | 51.99% ❌ |
| 0.30 | 37.94 | 0.18 | **99.52%** ❌❌ |

**Vega变化趋势**:
```
BS:  36.70 → 37.52 → 37.84 → 37.94  (↗ 增大)
PDE: 36.64 → 32.77 → 18.17 → 0.18   (↘ 减小，完全相反！)
```

## 🔬 诊断过程

### 步骤1: 排除AAD问题

**测试**: AAD梯度 vs 有限差分

```python

差异:      0.000008  ✅ AAD正确！
```

**结论**: AAD正确计算了 ∂V_PDE/∂σ，问题在于 V_PDE 本身。


**发现**: PDE Price对σ的敏感性在**递减**！

---

### 步骤4: 分析Crank-Nicolson格式的系数

**CN格式** (φ=0.5):

求解: `L_B * V^n = R_B * V^(n+1)`

其中:
```
L_B = I - 0.5*dt*D
R_B = I + 0.5*dt*D

D 是扩散-漂移算子:
D_jj = (∂²/∂S²) + r*(∂/∂S) - r*I
```

**有限差分系数** (at S=S_j):

```python
alpha = (σ²*S_j²/2) / dS²    # 扩散系数
beta  = r*S_j / (2*dS)        # 漂移系数
gamma = -r                    # 折现系数

# 三对角矩阵D的元素
l_j = alpha - beta            # 下对角
c_j = -2*alpha + gamma        # 主对角
u_j = alpha + beta            # 上对角
```

**关键发现**: `alpha ∝ σ²`

## 💥 根本原因：数值不稳定性

### 系数随σ增长

**在 S0=100, dS=2.0, dt=0.01**:

| σ | alpha | \|c_j\| | dt×spectral_radius | 状态 |
|---|-------|---------|-------------------|------|
| 0.15 | 28.13 | 56.30 | 1.13 | ❌ 不稳定 |
| 0.20 | 50.00 | 100.05 | 2.00 | ❌ 不稳定 |
| 0.25 | 78.13 | 156.30 | 3.13 | ❌ 严重不稳定 |
| 0.30 | 112.50 | 225.05 | 4.50 | ❌ 极其不稳定 |
| 0.40 | 200.00 | 400.05 | 8.00 | ❌ 完全失控 |

**观察**:
1. `alpha` 随 σ² 增长 (σ=0.30时是σ=0.15的4倍)
2. 主对角 `|c_j| ≈ 2*alpha` 也随σ²增长
3. 稳定性因子 `dt*spectral_radius` 远超 1.0 (理论上应 << 1)

---

### 数值阻尼机制

**理论稳定性条件**:

对于Crank-Nicolson格式，要求:
```
dt * max(|eigenvalue(D)|) << 1
```

实际情况:
```
σ=0.20: dt*spectral_radius = 2.00  (超出2倍)
σ=0.30: dt*spectral_radius = 4.50  (超出4.5倍)
```

**后果**:

1. **数值阻尼**: 大系数导致解在时间推进中被"阻尼"
2. **价格低估**: V(0,S0) 被系统性低估
3. **敏感性失真**:
   - 高σ时价格低估更严重
   - ∂V/∂σ 变小甚至为负
   - Vega完全错误

## 🎯 为什么当前网格失败

### 数值分析

**网格参数** (M=101, N=100):
- `dS = 200.0 / 101 ≈ 1.98`
- `dt = 1.0 / 100 = 0.01`

**在 σ=0.20 时**:
```
alpha = (0.2² × 100²/2) / 1.98² ≈ 50.0
dt*alpha = 0.01 × 50.0 = 0.5
```

**CFL条件** (Courant-Friedrichs-Lewy):

对于扩散方程，要求:
```
dt / dS² ≤ C / σ²
```

当前:
```
dt / dS² = 0.01 / 1.98² ≈ 0.00255

需要:
0.00255 ≤ C / σ²

σ=0.20: 右边 ≈ 0.025  ✅ (勉强满足)
σ=0.30: 右边 ≈ 0.011  ❌ (违反!)
```

**结论**: 网格对高σ不稳定。

---

### 为什么加密网格不起作用

**尝试过的**:
- M=51→101→151
- Vega误差稳定在12.68%

**原因**:

1. **空间网格不是瓶颈**:
   - 即使M=151，dS≈1.32仍太大
   - 需要dS<0.5才能稳定σ=0.30

2. **时间步长是关键**:
   - dt=0.01对高σ太大
   - 需要dt∝1/σ²

3. **成本爆炸**:
   - 要达到σ=0.30稳定：dS<0.5, dt<0.001
   - 需要M>400, N>1000
   - 计算时间从35s → 4000s (100×)

## 💡 根本原因总结

### 一句话总结

**Crank-Nicolson格式的扩散系数 α=(σ²S²/2)/dS² 随σ²增长，在当前网格分辨率下 (dS≈2, dt=0.01)，高波动率 (σ>0.25) 导致数值阻尼，价格被系统性低估，Vega敏感性失真甚至反向。**

---

### 详细链条

1. **扩散系数增长**: α ∝ σ² / dS²

2. **稳定性恶化**: dt × α 超出稳定区间

3. **数值阻尼**: 时间步进时解被人为"平滑"

4. **价格低估**:
   - σ=0.20: 低估0.93%
   - σ=0.30: 低估14.87%

5. **敏感性错误**:
   - V(σ+ε) 低估更严重
   - V(σ+ε) < V(σ-ε) (应该相反!)
   - Vega = ∂V/∂σ < 0 (错误符号)

6. **Volga崩溃**: Volga = ∂Vega/∂σ ≈ -190 (应该 +9.85)

## 🎓 理论支持

### Numerical PDE Theory

**Von Neumann稳定性分析**:

对于扩散方程 ∂u/∂t = α ∂²u/∂x²，显式格式:
```
稳定条件: α*dt/dx² ≤ 0.5
```

CN格式 (隐式):
```
无条件稳定 (理论上)
但实际精度需要: α*dt/dx² < 1
```

我们的情况:
```
α*dt/dS² = 50 × 0.01 / 1.98² ≈ 0.128  (σ=0.20, 勉强)
α*dt/dS² = 112.5 × 0.01 / 1.98² ≈ 0.287  (σ=0.30, 差)
```

### Black-Scholes PDE

标准形式:
```
∂V/∂t + (σ²S²/2)∂²V/∂S² + rS∂V/∂S - rV = 0
```

扩散项系数: `σ²S²/2`

**随σ变化**:
- σ=0.20: 系数 = 0.04×10000/2 = 200
- σ=0.30: 系数 = 0.09×10000/2 = 450 (2.25×)

**离散化后** (÷dS²):
- σ=0.20: α = 200/4 = 50
- σ=0.30: α = 450/4 = 112.5

→ 系数显著增大，需要更细网格
