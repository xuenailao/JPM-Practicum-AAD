## 方法概述

### 1. BSM解析解（Ground Truth）
- **类型**: 闭式解（Closed-form）
- **适用**: 仅限恒定波动率
- **精度**: 精确（机器精度）
- **速度**: <1ms ⚡
- **限制**: 无法处理时变/局部波动率

### 2. PDE Bumping（有限差分）
- **类型**: 数值求解 + 有限差分
- **适用**: 任何波动率曲面
- **精度**: 取决于步长和网格
- **速度**: 中等（需要多次PDE求解）
- **优势**: 简单、稳健

### 3. PDE AAD Edge-Pushing（真二阶AD）
- **类型**: 数值求解 + 自动微分
- **适用**: 任何波动率曲面
- **精度**: 高（一次前向传播）
- **速度**: 一次Hessian计算
- **优势**: 高效、精确二阶导数

## 问题诊断

### Vanna误差原因

**当前实现**:
```python
# 使用有限差分 + AAD
vanna = (np.sum(grad_up) - np.sum(grad_down)) / (2 * eps_S) / 100
```

**问题**:
- Vanna = ∂²V/∂S∂σ 是**混合偏导数**
- 当前方法对S做有限差分，对σ做AAD求和
- 但S不是PDE的参数，σ才是！

**正确方法**:
1. 需要对S的一阶导数再对σ求导
2. 或者使用真正的混合二阶AD
3. 或者用Bumping对两个方向都做有限差分

### Volga误差原因

**当前实现**:
```python
# 取Hessian对角线平均
hessian_diag = np.diag(hessian)
volga = np.mean(hessian_diag) / 10000
```

**问题**:
- Hessian是针对**离散参数**σᵢⱼ的
- ∂²V/∂σᵢ∂σⱼ ≠ ∂²V/∂σ²（全局）
- 简单平均对角线不正确

**正确方法**:
1. 需要对**全局扰动**计算导数
2. 或者用Bumping对整个σ表面扰动
3. 或者推导从离散Hessian到连续Volga的正确公式
