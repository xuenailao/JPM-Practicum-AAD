## 关键模块交互序列图

```
用户请求: 计算Vanna和Volga
     │
     ▼
┌─────────────────────────────────────────────────────────┐
│ SecondOrderGreeks.compute_vanna_volga()                 │
└─────────────────────────────────────────────────────────┘
     │
     ├─── 步骤1: 初始化求解器
     │    ┌────────────────────────────────┐
     │───▶│ LocalVolAdjoint(M=200, N=200)  │
     │    └────────────────────────────────┘
     │
     ├─── 步骤2: 构建邻接图
     │    ┌────────────────────────────────┐
     │───▶│ LocalVolAdjacency.build_full() │
     │    │ - 分析PDE三对角结构            │
     │    │ - 构建稀疏邻接表               │
     │    └────────────────────────────────┘
     │
     ├─── 步骤3: 创建Hessian计算器
     │    ┌────────────────────────────────┐
     │───▶│ HessianEdgePushing(solver, adj)│
     │    └────────────────────────────────┘
     │
     ├─── 步骤4: 正向求解
     │    ┌────────────────────────────────┐
     │───▶│ solver.solve_local_vol()       │
     │    │ 输出: V, price                 │
     │    └────────────────────────────────┘
     │
     ├─── 步骤5: 计算Jacobian
     │    ┌────────────────────────────────┐
     │───▶│ solver.compute_jacobian()      │
     │    │ 输出: ∂V/∂σ[i,n] 向量          │
     │    └────────────────────────────────┘
     │
     ├─── 步骤6: Edge-Pushing Hessian
     │    ┌────────────────────────────────┐
     │───▶│ hess_comp.compute_hessian()    │
     │    │                                │
     │    │ for (i,n) in params:           │
     │    │   for (j,m) in neighbors(i,n): │
     │    │     扰动σ[j,m]                 │
     │    │     重新计算∂V/∂σ[i,n]         │
     │    │     H[i,n,j,m] = Δ(∂V/∂σ[i,n])/ε
     │    │                                │
     │    │ 仅计算 ~P×5 项，不是 P²       │
     │    └────────────────────────────────┘
     │
     └─── 步骤7: 提取Greeks
          ┌────────────────────────────────┐
         ▶│ 从稀疏Hessian提取              │
          │                                │
          │ Vanna = Σ H[i,n,j,m] × 权重   │
          │ Volga = Σ H[i,n,j,m] × 权重   │
          └────────────────────────────────┘
               │
               ▼
          返回结果给用户
```
