# Volatility Sensitivity Benchmark

## 目的

测试5种Hessian计算方法在不同隐含波动率水平下的表现。

## 测试方法

1. **Bumping2** - 纯数值二阶差分法
2. **AAD+Bumping** - AAD一阶导数 + 数值二阶导数
3. **Double-AAD** - Forward-over-Reverse双重AAD
4. **Edge-Pushing** - Edge-Pushing算法优化
5. **BSM-Analytical** - BSM解析解（基准）

## 测试配置

### 期权参数（固定）
- S0 = 100（标的价格）
- K = 100（行权价，ATM平值期权）
- T = 1.0（期限1年）
- r = 5%（无风险利率）

### 波动率水平（变化）
测试5个不同的隐含波动率值：
- σ = 10%（低波动率）
- σ = 20%（标准波动率）
- σ = 30%（中等波动率）
- σ = 40%（高波动率）
- σ = 50%（极高波动率）

### 网格配置
- 粗网格：M=51, N=100
- 细网格：M=101, N=200

## 输出内容

对每个(σ, M, N)组合，测试所有5种方法，输出：

1. **计算时间**：每种方法的运行时间（毫秒）
2. **价格**：期权价格
3. **Gamma**：对S0的二阶导数
4. **误差表**：与BSM解析解对比的误差百分比
   - Price误差%
   - Gamma误差%
   - Vega误差%
   - Vanna误差%
   - Volga误差%

## 运行方式

```bash
python benchmark_varying_volatility.py
```

## 输出文件

- `benchmark_results/vol_benchmark_YYYYMMDD_HHMMSS.txt` - 完整测试结果
- `benchmark_results/vol_progress_YYYYMMDD_HHMMSS.json` - JSON格式进度文件

## 预期结果

### 时间性能
- Bumping2: 最快（~100-400ms）
- BSM-Analytical: 最快（<1ms）
- AAD+Bumping: 慢（~5-25秒）
- Double-AAD: 中等（~4-18秒）
- Edge-Pushing: 最慢（~96-764秒）

### 精度
所有方法应接近BSM解析解，误差：
- Price: <0.2%
- Gamma: <2%
- Vega: <0.5%
- Vanna: <3%
- Volga: ~27%（粗网格M=51），~10%（细网格M=101）

### 波动率敏感性

不同波动率水平下的观察：

1. **低波动率（σ=10%）**
   - 期权价格较低
   - Gamma较大（期权接近ATM时）
   - 数值方法可能更敏感

2. **标准波动率（σ=20%）**
   - 基准测试水平
   - 所有方法表现稳定

3. **高波动率（σ=40-50%）**
   - 期权价格较高
   - Volga（波动率二阶导数）增大
   - 测试方法在极端情况下的稳定性

## 测试意义

1. **验证方法一致性**：确认所有方法在不同波动率下计算一致
2. **发现数值不稳定性**：识别某些方法在特定波动率区间的问题
3. **评估计算效率**：对比不同波动率下的计算时间变化
4. **实际应用指导**：为实际交易场景选择合适的计算方法
